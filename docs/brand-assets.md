# Welfare Pride Brand Assets

The application references the approved assets below from the source tree so self-hosted deployments require no external asset service.

| Asset | Application path | Intended use |
| --- | --- | --- |
| Full logo | `client/src/brand-assets/welfare-pride-logo.svg` | Branded sign-in experience, expanded sidebar, About page, and footer |
| Icon mark | `client/src/brand-assets/welfare-pride-icon.svg` | Collapsed navigation, compact headers, and status marks |
| Wordmark | `client/src/brand-assets/welfare-pride-wordmark.svg` | Horizontal navigation and compact brand treatments |

The design system uses **Roboto** for all interface text, **`#5A92C9`** as the primary blue, and **`#D58240`** as the orange accent. White and near-black are used only as neutral surfaces and text colors; neither replaces the two official brand colors.
