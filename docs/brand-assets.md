# Welfare Pride Brand Assets

The application must reference the approved assets below exactly as uploaded. The files are stored outside the deployable source tree and served through permanent project storage.

| Asset | Application path | Intended use |
| --- | --- | --- |
| Full logo | `/manus-storage/welfare-pride-logo_37de8105.svg` | Branded sign-in experience, expanded sidebar, About page, and footer |
| Icon mark | `/manus-storage/welfare-pride-icon_7c43b462.svg` | Collapsed navigation, favicon-derived presentation, status marks, and compact mobile header |
| Wordmark | `/manus-storage/welfare-pride-wordmark_1a767708.svg` | Horizontal navigation and compact brand treatments where the full emblem is not appropriate |

The design system uses **Roboto** for all interface text, **`#5A92C9`** as the primary blue, and **`#D58240`** as the orange accent. White and near-black are used only as neutral surfaces and text colors; neither replaces the two official brand colors.
